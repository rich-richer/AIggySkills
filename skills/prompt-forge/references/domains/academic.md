# 学术与研究（Academic）

**什么时候读这个文件**：用户要写论文相关的东西——文献综述、开题报告、研究方法、审稿回复，或在读文献时想要结构化的帮助。
**读完你会得到**：学术场景必须问的 7 个参数、3 种合法的辅助交付物、**不得代写/不得学术不端**的执行细则，以及一个可直接用的文献综述提纲提示词。
**分工**：检索与信源分级见 `../modes/research.md`；引用锚定见 `../techniques/citation-anchoring.md`；学习内化见 `./self-learning.md`。

## 什么时候用

- 用户会说：「帮我写文献综述」「开题报告怎么写」「帮我理一下研究方法」「审稿意见怎么回」。
- 用户在读论文，要的是「读懂 + 组织」，而不是「替我写出一篇」。
- 涉及参考文献、数据、统计结论——**这是幻觉率最高的领域**，必须把「核对原文」写死。
- 用户没提学位/期刊要求与引用格式，而这两项决定能不能用。

## 行业参数

| 维度 | 必须问到 | 用户不答时的默认 | 采访编号 |
|---|---|---|---|
| 学位/期刊与阶段 | 本科/硕士/博士、开题/中期/投稿/返修 | 硕士学位论文开题阶段 | `I-G1` |
| 学科、范式与研究问题 | 定量/定性/混合、理论框架、一句话研究问题与假设 | 社会科学、定性为主；主题需先收敛 | `I-G2` / `I-L2` |
| 文献范围 | 数据库（CNKI/WoS/Google Scholar）、时间范围、语言 | 近 5 年、中英文核心期刊 | `I-R1` |
| 引用格式 | APA / GB/T 7714 / MLA / 期刊指定格式 | GB/T 7714（中文写作） | `I-G4` |
| 已有材料 | 已读文献、数据、导师意见 | 无，需要给检索策略 | `I-G5` |
| 使用边界 | 是否允许 AI 参与、学校/期刊的披露要求 | 只用于结构与语言层面，不代写 | `I-G3` |

## 常用体裁 × 3

### 1. 文献综述提纲（不是综述正文）

```
【研究问题】{{一句话}}，边界：{{研究对象/时间/地域}}。
【检索策略】数据库 + 关键词组合（中英）+ 纳入/排除标准 + 预计文献量。
【分类框架】按 {{理论流派/方法/结论倾向}} 分 {{3–5}} 类，每类 {{N}} 篇。
【争议点】{{2–3}} 个学界分歧，各写：谁主张什么、证据是什么。
【研究空白】现有文献没回答的 {{2}} 条，与我的研究问题的关系。
【待读清单】按"必读/选读"分级；每篇标"需我核对原文"。
```

适合谁：刚开始写综述、怕读不完也怕漏读的研究生；产出是检索与组织的脚手架，正文必须自己写。

### 2. 开题报告（结构与论证）

```
【背景】{{现实问题 + 研究缺口}}，各 1 段。
【研究问题与假设】RQ{{1–3}} + 对应假设/预期。
【方法与设计】样本、数据来源、变量与操作化、分析策略、伦理审查。
【可行性】时间表、数据可得性、风险与备选方案。
【贡献】理论贡献 + 实践意义（各 1 条，不吹大）。
```

适合谁：开题答辩前要经得起「你为什么这么设计」追问的人。

### 3. 审稿回复信（Response to Reviewers）

```
【总述】感谢 + 说明修改幅度（改了多少处、新增了什么）。
【逐条回应】审稿意见原文（编号）→ 我的回应 → 具体修改位置（页码/行号）→ 修改后原文摘录。
【未采纳的】说明理由，态度克制，不辩解不敷衍。
【版本说明】标注修改稿版本与日期。
```

适合谁：返修阶段的研究者；回应质量直接影响录用。

## 术语与合规边界

**必用术语（首次出现给中英对照）**

- 研究问题（RQ, Research Question）、假设（hypothesis）、操作化（operationalization）。
- 文献综述（literature review）、同行评议（peer review）、预印本（preprint）。
- 效度与信度（validity / reliability）、样本量、显著性水平（p 值）。
- 引用与参考文献（citation / reference）、查重（similarity check）。

**合规红线（学术场景最严，写进提示词）**

- **不得代写**：AI 可以用于选题讨论、结构梳理、检索思路、语言润色、精读辅助；**不得**生成可直接提交的论文正文、伪造数据或结论。
- **不得学术不端**：不编造数据、不篡改结果、不抄袭、不自我抄袭、不代写代投。
- **参考文献必须由作者核对原文**：模型生成的文献条目、DOI、页码幻觉率极高；凡出现文献，一律标「需核对原文」，不得直接进参考文献表。
- 遵守学校/期刊的 AI 使用规定与披露要求（各机构不同，**以本单位最新规定为准，待核实**）。
- 涉及人类被试的研究需伦理审查（IRB）与知情同意，隐私数据须脱敏；统计结论必须基于真实数据与既定方法，不由 AI 代为「给个结论」。

## 填好的示例

场景：硕士论文开题前，把「短视频对青少年注意力影响」这个宽主题收敛成综述提纲。可直接改题使用。

```
你帮我做文献综述的结构梳理。注意：我不是要你写综述正文，我需要检索策略、分类框架和待读清单，正文由我自己写。所有文献条目都必须由我核对原文。

## 我的情况
- 硕士论文开题阶段，传播学，定性为主 + 少量问卷。
- 研究问题（我先给一版，你可以指出它太大）：短视频使用与青少年持续注意力的关系。
- 文献范围：近 10 年，中英文核心期刊；数据库：CNKI、Web of Science、Google Scholar。
- 引用格式：GB/T 7714；学校要求 AIGC 使用需在附录披露，我会按要求披露。

## 你要产出
1. 把研究问题收敛成 2–3 个可操作的版本（写清各自的研究对象、时间范围、变量或分析单元）。
2. 检索策略：中英文关键词各 6–10 个 + 布尔组合 + 纳入/排除标准（含文献类型、样本、语言）。
3. 分类框架：把这批文献按 3–5 类组织，说明每一类回答的是哪个子问题。
4. 争议点 2–3 个：学界在哪些问题上结论不一致，各自的证据类型是什么。
5. 研究空白 2 条：现有文献没覆盖的部分，以及它与我的研究问题的关系。
6. 待读清单：按必读/选读分级，每篇给「为什么读它」。

## 边界（必须遵守）
- 不要生成参考文献列表；如果你提到具体文献，标「待我核对原文，不得直接引用」。
- 不要给"研究结论"或"数据显示"这类断言，我还没有数据。
- 不要替我写综述正文段落；只给结构和问题。
- 统计方法与样本量建议写成"可考虑的方案 + 需要与导师确认"。
- 输出开头一句提醒：「以下为结构建议，最终文献与结论须由作者核对原文并独立完成。」
- 格式：Markdown；检索策略用表格（数据库/关键词/限定条件）；全文 ≤1200 字；中文，术语首次给中英对照。
```

> 这段为什么这样写：明确「不要综述正文、只要结构和问题」，是把 AI 放在合规位置上；强制「文献标待核对、不生成参考文献表」直接对冲最高频的学术幻觉；要求三个可操作版本的研究问题，是因为学生最大的问题往往是问题太大而不是不会写。
> 换模型：推理模型给研究问题、材料、边界即可；小模型要给出分类框架的填表示例，否则会退回泛泛的综述套路。

## 常见坑

1. 让 AI 直接写论文正文 → 学术不端；只能用于结构、检索、润色，正文自己写。
2. 让 AI 生成参考文献 → DOI 与页码大概率是编的；一律要求标「需核对原文」。
3. 不写引用格式与文献范围 → 综述无法落地；先锁数据库、年限、格式。
4. 研究问题太宽（「短视频的影响」）、又不披露 AI 使用 → 先收敛成可操作版本，再把披露写进流程。
5. 把 AI 的统计结论当结果 → 数据与结论必须来自真实数据与既定方法。
