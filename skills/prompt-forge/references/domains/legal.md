# 法律与合规（Legal & Compliance）

**什么时候读这个文件**：用户要看合同、比条款、做合规自查、写法律科普，或准备和律师沟通。
**读完你会得到**：法律类需求必须问的 7 个参数、3 种交付骨架、**「不构成法律意见」**与法条幻觉的防法，以及一个可直接用的合同审阅提示词。
**分工**：检索与引用锚定见 `../modes/research.md`、`../techniques/citation-anchoring.md`；职场留痕问题见 `./workplace-communication.md`。

## 什么时候用

- 用户会说：「帮我看看这份合同有没有坑」「这条款什么意思」「我要不要签」「写个法律科普」。
- 用户要签合同、被违约、被投诉、要做隐私政策或用户协议——真实风险，不是作业。
- 用户问「我能不能告他」——这是法律意见，必须转成「争议事实梳理 + 要问律师的问题」。
- 用户所在法域不明确（中国大陆/香港/新加坡/美国某州），而法律问题高度依赖法域。

## 行业参数

| 法域与适用法律 | 哪个国家/地区、合同约定的适用法律与争议解决地 | 中国大陆法律 | `I-G3` |
| 当事人身份 | 甲方/乙方、个人/公司、是否消费者 | 公司对公司的 B2B 合同 | `I-G1` |
| 文件类型 | 买卖/服务/劳动/租赁/保密/股权/用户协议 | 服务合同 | `I-G5` |
| 所处阶段 | 签订前 / 履行中 / 已违约 / 已起诉 | 签订前审阅 | `I-G1` |
| 商业底线与风险偏好 | 哪些条款不可让、违约金上限、求稳还是抢单 | 保守；以不承担无限责任为底线 | `I-P1` / `I-G2` |

## 常用体裁 × 3

### 1. 合同风险清单（Contract Risk Review）

```
【结论】整体风险等级 {{高/中/低}}，最危险的 {{2–3}} 条。
【逐条】条款编号/原文摘要 | 风险点 | 风险等级 | 后果举例 | 建议改法（给修改示范句）。
【缺失条款】应写没写的：{{争议解决/知识产权归属/保密/解约/赔偿上限}}。
【谈判优先级与待问律师】必须改（底线）/ 争取改 / 可以接受各 {{N}} 条；要问律师的 {{3–5}} 个问题（带条款编号）。
```

适合谁：签合同前要做第一轮筛查的创业者、采购、销售；筛完再交给律师，省钱且高效。

### 2. 法律科普（面向公众）

```
【问题】用一句普通人的话提出（「公司让我签竞业协议，我能拒吗」）。
【规则】相关法律的一般规则是什么；**只写能核实的条文要点，标注需核对原文**。
【适用】在什么条件下适用、什么情况下不适用。
【两个极端案例】一个支持、一个不支持，说明差别在哪。
【行动建议】遇到这种情况先做什么、保留什么证据、什么时候必须找律师。
```

适合谁：做法律科普的自媒体、企业合规培训；不合规写法通常是把科普写成「保证能赢」。

### 3. 争议准备（Dispute Prep）

```
【时间线】按日期列事实，每条只写可举证的事实（谁、何时、做了什么）。
【证据清单】已有：{{合同/聊天记录/转账凭证/邮件/录音}}；缺：{{}}。
【诉求与抗辩】我方能主张什么、对方可能怎么反驳。
【时效与程序】诉讼时效、协商/调解/仲裁/诉讼的先后顺序（标注需核实）。
【要问律师的】{{5}} 个问题 + 我该带哪些材料。
```

适合谁：已经发生纠纷、准备找律师的人；把混乱的事实先整理成可读材料，律师费能省一半。

## 术语与合规边界

**必用术语（首次出现给中英对照）**

- 违约责任、不可抗力（force majeure）、定金与订金（法律效果不同）、管辖/仲裁条款。
- 诉讼时效、解除权、格式条款（standard-form clause）、保密协议（NDA）。
- 竞业限制、举证责任（burden of proof）、损害赔偿、继续履行。

**合规红线（必须出现在提示词与输出里）**

- **必须声明「本内容为法律信息整理，不构成法律意见，不能替代持牌律师」**。
- **不编造法条编号、案号、判例、法规名称**：模型在这方面幻觉率极高；需要条文时要求「给原文要点 + 标注『需核对现行文本』」，宁可少写。
- 法律会修订：结论必须标注「以最新有效版本为准（待核实）」与法域。
- 不指导伪造证据、规避法律、转移资产、逃税；涉及刑事风险直接建议找律师。不预测诉讼结果、不承诺胜诉率。
- 不代拟可直接提交的正式文书（起诉状/答辩状/律师函），只能给草稿并标「须律师审核」；合同与个人信息脱敏（当事人、金额、证件号、联系方式）。

## 填好的示例

场景：一份对外服务合同，签前做第一轮风险审阅。条款内容可替换。

```
你帮我审一份服务合同，我是乙方（提供服务的公司），对方是甲方（某制造企业）。目标：签前做第一轮风险筛查，找出不能签的点和必须改的条款，然后我把结果带给律师。

## 基础信息
- 法域：中国大陆法律；争议解决地约定为甲方所在地法院。
- 合同标的：为甲方提供 6 个月的数据看板开发与运维服务，合同金额 48 万元，分 3 期支付。
- 我的商业底线：不接受无限赔偿责任；不接受验收标准由甲方单方认定；不接受免费无限期运维。

## 合同全文
（我贴在下面，按条款编号分段。若我漏贴附件，请以「附件未提供」标注，不要假设内容。）

## 你要产出
1. 整体风险等级 + 最危险的 3 条（用条款编号说话）。
2. 逐条风险表：条款编号 | 风险点 | 等级（高/中/低）| 可能后果 | 建议改法（给一句可直接替换的示范措辞）。
3. 缺失条款清单：争议解决、知识产权归属、保密、解约与结算、赔偿上限、验收标准，逐项说明"有没有/够不够"。
4. 谈判优先级：必须改的 3 条（我的底线）、争取改的 3 条、可以接受的 2 条；外加付款与验收节点风险（哪一期最容易拿不到钱）。
5. 我要问律师的 5 个问题。

## 边界（必须遵守）
- 不要给我确定的「这条一定无效/一定有效」结论；写成「存在被认定为 X 的风险」。
- 涉及法条时，只写条文要点并标注「需核对现行有效文本（待核实）」，不要编条号。
- 不预测诉讼结果，不评估胜诉概率。
- 不替我发律师函、不起草可直接提交的正式文书；如需草稿，标「草稿，须律师审核」。
- 输出开头固定一句：「本内容为合同风险信息整理，不构成法律意见，不能替代律师审阅。」
- 格式：Markdown 表格 + 清单；全文 ≤1200 字；表格里引用原文用引号并注明条款编号。
```

> 这段为什么这样写：把身份（乙方）和商业底线写进去，模型才会按「我要不要签」排序风险，而不是泛泛列法条；强制「不编条号 + 需核对现行文本」，是压住法条幻觉的唯一办法；要求给可替换的示范措辞，是因为风控清单如果只指出问题、不给句子，业务方根本改不动。
> 换模型：推理模型给身份、底线、边界即可；小模型必须保留固定表格列与「需核对」的硬约束，否则会自信地给出条号。

## 常见坑

1. 让 AI 直接给法条编号与判例 → 幻觉重灾区；改成「给条文要点 + 标注需核对现行文本」。
2. 不说自己站在哪一方 → 审出来的风险不分轻重；先写明甲方/乙方与商业底线。
3. 把风险清单当律师意见直接用 → 高风险合同必须送律师；AI 只做第一轮筛查。
4. 不写法域、只审已写的条款 → 同一份条款在中国大陆和香港可能结论相反；缺失条款固定单列一节。
5. 输出没有免责声明却要发给对方 → 声明写进固定开头，并区分「内部版/可对外版」。
