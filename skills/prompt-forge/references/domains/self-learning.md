# 自学与知识内化（Self-Learning）

**什么时候读这个文件**：用户要学一门新东西、把看完的材料变成自己的、或者想知道「我到底掌握没掌握」。
**读完你会得到**：学习类需求必须问的 8 个参数、3 种可交付的学习产物骨架、学习领域的硬边界，以及一个可直接跑的两周学习计划提示词。
**分工**：学习任务的问法（当前水平、目标、形式偏好）见 `../modes/learning.md`；逐步引导、反思校对属于技法层。本文件只写「自学」这个场景特有的东西。

## 什么时候用

- 用户会说：「我想学 X，怎么开始」「帮我把这个视频/书整理成笔记」「我该怎么复习」「给我出几道题」。
- 用户手上有材料（视频、课程、官方文档、自己的笔记），但不知道按什么顺序学、学到什么程度算会。
- 用户学过一遍又忘了，需要的是复习机制和自测，不是再读一遍。
- 用户把「学习」说成「帮我总结一下」——总结是手段，可验收的产出才是目的，先问清要产出什么。

## 行业参数

| 维度 | 必须问到 | 用户不答时的默认 | 采访编号 |
|---|---|---|---|
| 当前水平 | 零基础 / 有相邻领域经验 / 用过但不系统 | 有日常使用经验、无系统知识 | `I-L1` |
| 目标与验收 | 学完能做出一件什么具体的事（可观测） | 产出 1 个能跑通的最小作品 | `I-L2` |
| 时间预算 | 总共几小时、每天多久、多久复习一次 | 每天 30–45 分钟，持续 2 周 | `I-G2` |
| 材料来源 | 指定教材/视频/文档，还是允许自己检索 | 只用用户给的材料 + 通用知识 | `I-R1` |
| 产出形式 | 笔记 / 手册 / 思维导图 / 复习卡 / 小项目 | 结构化手册 + 自测题 | `I-L2` |
| 难度跳跃 | 每单元难度跨度、是否允许超纲 | 单次只引入 3–5 个新概念 | `I-L1` |
| 用途 | 自用 / 考试 / 面试 / 交付给同事 | 自用，能上手 | `I-G1` |
| 语言与术语 | 中文为主还是保留英文原词，术语密度 | 中文正文 + 首次出现给中英对照 | `I-G1` |

## 常用体裁 × 3

### 1. 学习计划（带验收单元）

```
【目标】{{两周后能独立完成的具体产出}}；验收方式：{{谁来验收/看什么}}。
【起点】已会：{{}}；不会：{{}}；只想解决：{{}}。
【拆解】{{N}} 个单元，每单元写：学什么 → 练什么 → 怎么算过关（可观测）→ 预计耗时。
【复习】每次开始前 10 分钟回顾上次的 {{3}} 个问题；第 4、8、14 天各做一次混合自测。
【放弃线】如果 {{某单元}} 超过 {{2 倍预计时间}} 仍未过关，就退回上一单元或换材料。
```

适合谁：有明确时间窗（周内要学会、月底要用）的自学者；最怕的是「计划很漂亮但没有验收标准」。

### 2. 材料内化手册（把视频/书/文档变成可复习的东西）

```
【一句话精华】用 ≤30 字说清这份材料最核心的一句。
【结构还原】把材料拆成 {{3–6}} 个板块，每块写：讲了什么 → 为什么重要 → 我可以用在哪。
【可操作 SOP】把"怎么做"写成编号步骤，每步包含：动作 + 判断标准 + 常见失败点。
【术语卡】{{8–15}} 个术语：中文名 / 英文名 / 一句话解释 / 一个反例。
【自测题】{{6–10}} 题，分三层：回忆题、应用题、判断题（给一个错误说法让人挑错）。
【复习卡】{{8–12}} 张，正面问题、背面答案，答案 ≤2 行。
```

适合谁：看完视频/书怕忘、要长期复用的人；成品按「分板块 + 表格 + 复习卡」排版最好用，读者隔一周还能快速捡回来。

### 3. 费曼式自测与错题复盘

```
【选点】从 {{材料}} 里挑 {{3}} 个最容易误解的概念。
【我先讲】请先只给我问题，我用自己的话答，你再指出我错在哪、漏了什么。
【追问】针对我的答案连续追问 3 层「为什么」，直到我说不出来为止。
【改写】把我的错误答案改写成一句正确的、我能背下来的话。
【迁移】给我 1 个新场景，问我这个概念在这里还成立吗。
```

适合谁：以为自己懂了结果一考就废的人；也适合面试/考试前 48 小时的突击自测。

## 术语与合规边界

**必用术语（首次出现给中英对照）**

- 费曼技巧（Feynman Technique）：用自己的话讲给别人听，讲不下去的地方就是没懂的地方。
- 检索练习（retrieval practice）> 重复阅读：合上书回忆比再看一遍有效。
- 间隔重复（spaced repetition）：第 1、3、7、14 天各复习一次。
- 刻意练习（deliberate practice）：只练不会的部分，带即时反馈。
- 最近发展区（ZPD, Zone of Proximal Development）：难度略高于当前水平才有效。
- 认知负荷（cognitive load）：一次塞太多概念，学习效率反而下降。
- 主动回忆 / 被动重读、知识图谱、可观测学习目标（observable objective）。

**边界与合规**

- **不承诺速成、不承诺「学完就能月入 X」**：把结果写成可观测的产出，不写收益承诺。
- **AI 讲解不是权威**：涉及事实、版本号、API 行为、医学法律金融结论，要求标注来源并提示「需核对官方文档」；人设不能给事实背书（见 `../anti-patterns.md` 的已证伪清单）。
- **版权**：不要求模型大段复制付费课程/书籍原文；改写并注明出处，引用保留短句。
- **学习产出用于学术场景**（论文、作业、毕业设计）时，不得代写，须遵守 `./academic.md` 的学术规范。
- 健康类学习（减脂、训练、康复）须转到 `./health.md` 的边界，不给医疗建议。
- 不要把用户的学习数据、考试信息、个人履历写进公开分享材料。

## 填好的示例

场景：用户手上有 1 份 88 行的提示词笔记 + 1 个 40 分钟视频，想在 10 天内真正会用，而不是「看过了」。

```
你是我的学习教练。只做三件事：拆计划、出练习、验收我。不要替我总结全文，我不需要读后感。

## 我的现状
- 已经会：日常用 ChatGPT / Gemini 聊天、让 AI 改文章。
- 还不会：写能反复使用的提示词、区分推理模型和普通模型、判断输出好坏。
- 每天能投入：40 分钟，晚上；10 天后要能给同事讲一次 15 分钟分享（这就是验收）。

## 材料（只用这两份，不要引入其他教程）
1. 我的笔记《15分钟学会提示词9大秘籍》（88 行，含乔哈里视窗、乒乓球迭代法、9 条秘籍）。
2. 一个 40 分钟视频的逐字稿（我另外贴给你）。

## 你要交付
1. 10 天计划表：每天 40 分钟，格式为「今天学什么 / 练什么 / 怎么算过关」，每天只引入 3–5 个新概念。
2. 每天 1 个练习：必须是「改我写的提示词」或「判断两份提示词哪份更好并说明理由」，不给选择题。
3. 第 3、6、10 天各一次 10 分钟混合自测，用我前几天的错题出题。
4. 一份 15 分钟分享的提纲（最后一天生成，用来验收）。

## 硬性要求
- 每个概念讲完必须给一个「反例」：什么样的写法是错的。
- 凡引用材料原文，标出来自哪份材料的哪一段；不确定的地方写「材料未覆盖，需核实」。
- 不承诺「学完就能变现」，只承诺能通过最后那次分享。
- 你的角色只是语气，事实以材料和官方文档为准；涉及模型能力差异时按「推理模型 / 通用聊天模型」分情况说，不要一刀切。
- 如果我在某天卡住超过 2 倍预计时间，你先让我退回上一个单元，别加新内容。

先输出第 1 天的计划 + 练习，我做完再给第 2 天。不要一次把 10 天全发给我。
```

> 这段为什么这样写：把「验收」定成一个可交付物（15 分钟分享），学习才有终点；限制「只用这两份材料」+「材料未覆盖写待核实」直接压住幻觉；要求「一次只给一天」是把长任务切段，避免模型一次吐 10 天计划后用户照着走偏（李厂长秘籍 8：指令过多要拆）。
> 换模型：推理模型只给目标/验收/边界，删掉「先给第 1 天」这类过程指令也可以；小模型必须保留「一次只输出一天」和输出格式，否则会跑偏。

## 常见坑

1. 只说「帮我梳理一下 X」→ 拿到的是一篇读后感；改成「10 天后我要能做出 Y」。
2. 计划没有验收标准（「第 3 天：了解乔哈里视窗」）→ 改成「能用自己的话解释 + 举一个反例」。
3. 让 AI 一次输出全部内容 → 认知负荷爆掉；改成按天/按单元分段交付。
4. 笔记做成纯摘抄 → 复习时等于重读；至少要有「我可以用在哪」+ 自测题。
5. 复习没有触发点 → 把复习日期写死在计划里（第 1/3/7/14 天），不靠自觉。
6. 把 AI 的讲解当权威 → 涉及版本、API、政策的事实，要求给来源并回官方文档核对。
