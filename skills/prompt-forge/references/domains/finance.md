# 金融与投资分析（Finance）

**什么时候读这个文件**：用户要读财报、做预算与成本分析、看投资标的、写理财/保险咨询内容、整理融资材料。
**读完你会得到**：金融类需求必须问的 7 个参数、3 种交付骨架、**「不构成投资建议」**等硬边界，以及一个可直接用的财报阅读提示词。
**分工**：数据抽取与结构化见 `../modes/extraction.md`；风险论证与反方观点见 `../techniques/citation-anchoring.md` 与 `../modes/research.md`。

## 什么时候用

- 用户会说：「帮我看看这家公司的财报」「做个预算表」「这只基金/股票值不值得买」「帮我写理财科普」。
- 内容涉及钱、收益、风险、税务——输出会被当成决策依据，边界比文采重要。
- 用户给了年报/招股书/研报，要「读懂并给出判断」，而不是「翻译成中文」。
- 用户想让你预测价格或收益率——这类要求必须转成「情景分析 + 假设」。

## 常用体裁 × 3

### 1. 财务分析备忘（Financial Analysis Memo）

```
【结论】{{经营质量判断 + 最重要的 1 个风险}}，置信度 {{高/中/低}}。
【趋势】近 {{3–5}} 年收入、毛利率、经营现金流的方向与拐点，数字带期间。
【结构】收入构成、成本结构、费用率变化，指出异常项。
【质量】利润与现金流是否匹配；应收/存货/合同负债的变化说明了什么。
【同业】与 {{2–3}} 家可比公司对比（标口径差异）。
【风险与反方】{{3}} 条看空理由 + 哪一条无法排除。
```

适合谁：要判断一家公司「赚的是不是真钱」的分析者；投资决策前的最小功课。

### 2. 预算与现金流模型（Budget & Cash Flow）

```
【假设表】收入驱动（量 × 价）、成本驱动、人力、账期；每条假设给依据。
【三档情景】保守/中性/乐观，各档触发条件。
【月度现金流】收入 → 回款（按账期）→ 支出 → 净现金 → 累计现金。
【安全边际】最低现金余额出现在第几个月，缺口多少。
【敏感性】{{2–3}} 个关键假设 ±20% 对现金的影响。
```

适合谁：创业公司/部门负责人做年度预算、判断「什么时候会缺钱」。

### 3. 投资研究笔记（Research Note）

```
【标的与视角】{{资产}}，{{持有/观察/回避}}，期限 {{}}。
【核心论点】{{1–3}} 条，每条给证据与来源。
【估值/定价逻辑】用 {{PE/PS/DCF/可比}}，写明假设与不确定性。
【反方】{{3}} 条最可能让自己亏钱的理由。
【风险与止损】最大可承受回撤 {{X%}}，触发减仓的条件。
【声明】本文为个人研究记录，不构成投资建议。
```

适合谁：做自投研究、要把想法写成可复查记录的人。

## 术语与合规边界

**必用术语（首次出现给中英对照）**

- 三张报表：利润表 / 资产负债表 / 现金流量表；息税折旧摊销前利润（EBITDA）、自由现金流（FCF）、应收周转、合同负债。
- 同比（YoY）/环比（QoQ）、可比公司（peer）；所有数字必须带口径（measurement basis）。
- 市盈率（PE）/市销率（PS）/现金流折现（DCF）、加权平均资本成本（WACC）。
- 敏感性分析（sensitivity analysis）、最大回撤（max drawdown）。

**合规红线（必须写进提示词，且出现在输出里）**

- **必须声明「本文为信息整理与分析框架，不构成投资建议」**；面向公众的内容不得给出「买入/卖出」的确定性指令。
- **不承诺收益、不预测确定价格**：只给情景与假设，目标价须标「基于 X 假设的测算」；未公开信息（内幕信息）与他人账户数据一律不用；不代客理财、不荐股、不给具体买卖时点；基金/保险须提示「以产品合同与持牌机构披露为准」。
- 税务与跨境合规以当地法规与持牌顾问为准（**待核实**），不做税务筹划建议；数字必须带来源/期间/口径，汇率标取值日；涉及个人财务状况建议咨询持牌理财顾问，AI 输出只作自查清单。

## 填好的示例

场景：读一家 A 股制造业公司的年报，输出一页分析备忘。数字可替换。

```
你帮我读一份上市公司年报并写一页分析备忘。读者是我自己（做长期投资，能承受 20% 回撤），不是公开内容。

## 材料
我贴给你的是该公司 2023–2025 三个年度的年报节选（管理层讨论、三大报表、附注中的收入构成）。
只用我提供的材料；材料里没有的信息写「材料未覆盖」，不要用你的记忆补，也不要给新闻里的传闻。

## 你要产出
1. 一句话结论：经营质量（好/一般/恶化）+ 最需要警惕的 1 个风险。
2. 趋势表：营业收入、毛利率、净利率、经营现金流净额、应收账款周转天数，三年数据 + 同比，标注口径与单位。
3. 质量检验：净利润与经营现金流的差距在哪几年出现、可能原因（列出候选解释，不要下定论）。
4. 收入结构变化：哪块业务在增长/萎缩，附注里有没有口径变更。
5. 反方 3 条：最能推翻"经营稳健"这个结论的三个理由。
6. 我还需要补充的材料清单（例如：同业年报、产能与订单披露）。

## 边界（重要）
- 给结论时必须区分「材料中的事实」与「我的推断」，推断要标注依据。
- 不要给买卖建议、不要预测股价、不要给目标价。
- 不确定的会计口径变更、非经常性损益处理，标「需核对附注原文」。
- 输出末尾固定加一行：「本文为信息整理与分析框架，不构成投资建议。」
- 格式：Markdown；表格 ≤6 列；全文 ≤800 字；中文，术语首次给中英对照。
```

> 这段为什么这样写：把「只用我提供的材料 + 材料未覆盖就明说」放在最前，是压住财报幻觉的唯一有效手段——模型对公司的记忆常与最新年报冲突；强制「事实 vs 推断」分段，避免把推断当成公司披露；免责声明指定为固定末尾行，不靠模型自觉。
> 换模型：推理模型给目标+边界即可，删掉「1–6 条」这种步骤约束也行；小模型必须保留固定表头与字数上限。

## 常见坑

1. 让 AI「预测股价/给目标价」→ 拿到的只是措辞漂亮的猜数；改成「三档情景 + 触发条件 + 假设」。
2. 不写口径与期间（「毛利率提升了」）→ 无法核对；每个数字带期间、单位、口径。
3. 不看现金流只看利润 → 利润可以调节，现金流更接近真实；强制加「利润与现金流匹配度」一栏。
4. 缺反方观点 → 只看到支持自己立场的内容；固定要求「3 条看空理由」。
5. 输出里没有免责声明 → 面向公众发布时风险很高；把声明写进提示词的「固定末尾行」。
