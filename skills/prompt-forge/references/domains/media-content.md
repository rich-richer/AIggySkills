# 自媒体内容（Media Content）

**什么时候读这个文件**：用户要做内容——短视频选题与脚本、公众号长文、小红书笔记、账号定位、系列栏目、爆款拆解。
**读完你会得到**：自媒体必须问的 8 个参数、3 个主力平台的体裁骨架、广告标识与版权红线，以及一个可直接用的 60 秒口播脚本提示词。
**分工**：创作结构（钩子、叙事、多方向）见 `../modes/creative.md`；图像/视频模型的提示词写法见 `../modes/image-video.md`（主体+场景+动作+镜头+光线+风格+比例，一个提示词只做一个场景）。本文件只写平台与合规语境。

## 什么时候用

- 用户会说：「帮我写条视频脚本」「这个选题怎么写标题」「公众号文章帮我搭个结构」「小红书笔记文案」。
- 用户有账号和定位，要的是「能直接拍/直接发」的稿件，不是创意点子清单。
- 用户要复盘一条内容为什么爆/为什么不爆（拆解，而不是模仿）。
- 用户说「帮我写爆款」——「爆款」不是可执行目标，先问清平台、账号、受众、要什么动作。

## 行业参数

| 维度 | 必须问到 | 用户不答时的默认 | 采访编号 |
|---|---|---|---|
| 平台与体裁 | 抖音/视频号/B 站/公众号/小红书/知乎，图文还是视频 | 视频号口播 + 小红书图文各 1 条 | `I-G1` |
| 账号定位 | 谁在讲、讲给谁、和别人有什么不同 | 个人 IP，职场效率方向 | `I-C1` |
| 观众与场景 | 观众是谁、在什么状态下刷到（通勤/睡前/焦虑时） | 25–40 岁职场人，碎片时间 | `I-G1` |
| 内容形态 | 口播 / 剧情 / 测评 / 盘点 / 教程 / 访谈 | 口播 + 案例 | `I-G1` |
| 目标动作 | 涨粉 / 完播 / 评论 / 私信 / 带货 / 进私域 | 完播 + 评论 | `I-G2` |
| 时长与节奏 | 视频秒数、公众号字数、几个信息点 | 60 秒 / 1500 字 / 3 个信息点 | `I-C3` |
| 素材与版权 | 自有素材、可商用素材、二创授权 | 只用原创与可商用素材 | `I-G5` |
| 商务与合规 | 是否有广告/带货/医疗金融教育等特殊类目 | 按无广告处理，出现商业内容必须标 | `I-G3` |

## 常用体裁 × 3

### 1. 短视频脚本（口播为主）

```
【一句话主题】{{观众看完能拿走的那一句话}}。
【黄金 3 秒】用 {{反常识/具体数字/直接点名痛点}} 开头，第一句不许自我介绍。
【结构】钩子 → 一个具体场景/案例 → 3 个要点（每点 ≤15 秒）→ 一句可执行的建议 → CTA。
【口播稿】按秒切分：{{0–3s}}{{3–15s}}…，每段 ≤2 句，用口语短句。
【画面提示】每个段落写：镜头（特写/中景）、动作、字幕关键词；只写必要的。
【CTA】{{关注/评论一个问题/私信关键词}}，只给 1 个动作。
```

适合谁：日更口播、要把抽象经验讲成人话的创作者；也是「一条内容只讲一件事」的最小可执行单位。

### 2. 公众号长文（结构与留存）

```
【标题】{{具体利益点 + 受众身份}}（不用感叹号堆叠）。
【开头 150 字】用一个具体场景或一个反常识结论抓住人，不铺垫行业背景。
【结构】{{3–4}} 个小标题，每个小标题 = 一个判断句；每节 300–500 字，含 1 个案例。
【证据】{{数据/案例/引用}}，标注来源；没来源的判断写成「我的经验」。
【结尾】一句总结 + 一个具体行动 + 一个开放问题（为评论）。
【写作约束】禁用「赋能/抓手/闭环」等词；每段 ≤4 行。
```

适合谁：做深度内容、靠长文建立信任的公众号作者；读者是「收藏了再看」的人。

### 3. 小红书图文笔记（封面 + 正文 + 标签）

```
【封面文案】{{≤12 字}}，写「结果」或「反差」，不写标题党式的假信息。
【正文开头】第一句直接说这条笔记解决什么问题（平台会截断前两行）。
【正文化】{{3–5}} 条要点，用短句 + 换行；每条给一个可照做的动作。
【可信度】写清适用人群与不适用人群，避免「人人都适用」。
【标签】{{5–8}} 个：1 个大词 + 2–3 个精准词 + 2–3 个场景词。
【互动】结尾问一个容易回答的具体问题。
```

适合谁：做种草、教程、清单类笔记的创作者；平台规则变化快，发布前需按当期规则复核。

### 补充：爆款拆解（复盘，不是模仿）

```
【数据基线】{{播放/完播/互动}} 与该账号历史中位数对比（说明数据口径与时间）。
【逐段拆】0–3 秒钩子类型、信息密度、情绪曲线、转折点在第几秒。
【可迁移结构】抽象成 {{1–3}} 条可复用规则，每条给一个反例。
【不可迁移部分】哪些依赖账号信任度/嘉宾/时机，换人就不成立。
```

适合谁：已经有内容、要把偶然爆款变成方法的人（用户既有 skill 里也有类似板块，可直接对齐）。

## 术语与合规边界

**必用术语（首次出现给中英对照）**

- 钩子（hook）、完播率、互动率、信息密度（information density）、行动号召（CTA, Call to Action）。
- 人设（persona）：只影响语气、视角、受众适配，**不要用它给事实背书**——「你是世界级专家」对语气有用，对事实召回无益甚至有害（见 `../anti-patterns.md`）。
- 爆款拆解、选题库、系列化栏目、私域（private domain）、种草、带货。
- 广告标识（ad disclosure）、软广/硬广、二创（derivative work）、可商用素材（commercially usable asset）。

**合规红线**

- **商业内容必须可识别为广告**：涉及付费推广、带货、品牌合作，正文或简介中标注「广告/合作」，按平台当期规则与《广告法》执行。
- 不用绝对化用语与虚假承诺（「最有效」「7 天涨粉一万」「保证变现」）；数据引用注明口径与时间。
- **特殊类目叠加资质**：医疗健康 → `./health.md`；金融/理财 → `./finance.md`；教育培训招生 → `./education-training.md`。没有资质不写疗效、收益、提分承诺。
- **不搬运、不洗稿**：引用他人内容须注明并控制篇幅；二创需授权；配图/音乐/字体的商用授权要核实。
- 不编造数据、用户评价、销量、履历；不伪造「真实案例截图」。
- 涉及他人肖像、聊天记录、客户信息，须脱敏与授权。
- AI 生成内容按平台要求标注（各家规则不同，**以发布时平台最新规则为准，待核实**）。

## 填好的示例

场景：一个讲 AI 效率的账号，拍一条 60 秒视频号口播。可以直接改选题使用。

```
你帮我写一条 60 秒视频号口播脚本。我是做「AI 工具提效」的个人 IP，观众是 25–40 岁职场人。

## 这条要解决的事
选题：为什么大多数人用 AI 写东西还不如自己写。
目标动作：完播 + 评论（想让观众在评论区说自己的失败场景，不要引导关注）。

## 内容要求
1. 黄金 3 秒：用「反常识」开头，第一句不能是自我介绍、不能是「大家好」。
2. 中间必须有一个我自己能讲的真实场景：我用 AI 写周报，第一版全是套话，改三遍才能用（这个我确实经历过，可以讲）。
3. 给出 3 个要点，每个要点一句话说清、配一个反例；要点之间用口语过渡，不要念小标题。
4. 结尾给 1 个观众今天就能做的动作 + 1 个评论区问题（具体，容易回答）。
5. 全程口语短句，每句 ≤15 字；不出现「赋能、抓手、闭环、底层逻辑」这类词。

## 输出格式
- 先给一句话主题（≤30 字）。
- 再给分段时间轴表：0–3s / 3–15s / 15–40s / 40–55s / 55–60s，每段写：口播原句 + 镜头提示 + 字幕关键词。
- 最后给 3 个备选标题（都不得夸大或承诺效果）。

## 边界
- 不承诺「学会就能涨粉/变现」。
- 不虚构数据；如需举例只能用我上面提供的那个真实场景。
- 不出现任何品牌名与产品名，避免变成广告；如我后续要求提产品，你给我加一句「广告标注」提醒。
```

> 这段为什么这样写：把「黄金 3 秒」写成可检验的约束（第一句不许自我介绍），比写「要有吸引力」有用；只给一个真实场景，等于给模型一个可复用的素材锚点；三个备选标题 + 广告提醒，是在提示词里预置合规动作。
> 换模型：给图像/视频生成模型时改写法——只描述画面与运动（主体 + 场景 + 动作 + 镜头 + 光线 + 风格 + 比例），一个提示词只做一个场景，负面要求写「墙面干净」而不是「不要墙」；文案类模型补 2–3 条示例会更贴平台语气。

## 常见坑

1. 只写「帮我写个爆款文案」→ 无平台、无受众、无动作，输出必然是通稿；改成具体平台 + 目标动作。
2. 标题与内容不符（标题党）→ 完播率反噬且违反平台规则；标题承诺的必须在内容里兑现。
3. 一个提示词同时要「视频脚本 + 小红书 + 公众号」→ 三种平台语言完全不同；一个平台一个提示词。
4. 只写口播稿不给画面/字幕提示 → 拍摄时没法执行；至少要有一段镜头与字幕关键词。
5. 用 persona 背书事实（「你是顶级专家所以你说的一定对」）→ 对事实召回有害；事实靠来源，人设只用于语气。
6. 忽略广告标识与素材授权 → 商业内容不标广告、用未商用授权的 BGM，都是常见翻车点。
