# 深度调研与咨询（Research & Consulting）

**什么时候读这个文件**：用户要的不是「介绍一个话题」，而是「搞清某个行业/公司/产品，然后给一个能拍板的结论」。
**读完你会得到**：这个领域必须追问的 8 个参数、3 种最常交付的体裁骨架、术语与合规红线，以及一个可直接复制填写的完整提示词。
**分工**：通用调研骨架与信息取舍见 `../modes/research.md`；引用锚定手法见 `../techniques/citation-anchoring.md`。本文件只写「调研/咨询这个行业特有」的东西。

## 什么时候用

- 用户会说：「帮我做个行业调研」「这个赛道还能不能进」「给我一份竞品分析」「做个可行性研究」「帮我看看这家公司」。
- 用户心里已经有一个决策（投/不投、进/不进、卖/不卖），但缺证据链，也缺反方意见。
- 用户给了材料（年报、招股书、访谈纪要、新闻剪报），要求「看完给结论」，而不是「帮我总结一下」。
- 用户说的「调研」其实只是想找一堆资料链接——那是检索，不是咨询；先确认他要不要决策级输出。

## 行业参数

| 维度 | 必须问到 | 用户不答时的默认 | 采访编号 |
|---|---|---|---|
| 决策者与决策问题 | 谁看、看完要做什么决定、什么时候拍板 | 决策者＝用户本人；问题是「要不要做」 | `I-P1` |
| 分析单元 | 行业 / 公司 / 产品 / 地区 / 人群，边界怎么切 | 中国大陆市场、单一行业 | `I-G1` |
| 时间窗口与时效 | 数据截止到哪一年/季度，多旧的资料不用 | 近 24 个月公开信息 | `I-R1` |
| 信源分层 | 哪些是一手（访谈/财报/招标公告）、哪些是二手（媒体/研报），允许用哪些 | 用用户已有材料 + 公开信息，不编来源 | `I-R1` |
| 口径定义 | 市场规模按 GMV / 收入 / 出货量？谁的口径 | 强制写口径，不写就标「待核实」 | `I-P2` |
| 交付形态 | 一页纸备忘 / 完整报告 / 路演 deck / 结论 + 风险表 | 一页纸结论 + 证据附录 | `I-R2` |
| 结论倾向 | 要明确推荐，还是只给选项和权衡 | 明确推荐 1 个 + 备选 1 个 | `I-P2` |
| 保密与利益冲突 | 是否涉及客户名、未公开信息、竞业限制 | 不出现可识别客户信息 | `I-G3` |

## 常用体裁 × 3

### 1. 一页纸决策备忘（Decision Memo）

```
【结论】用 1–3 句话给出建议：{{做什么 / 不做什么 / 先做什么}}。
【理由】支撑结论的 3 条证据，每条带来源：{{证据}}（来源：【{{文件名}}|{{页码/章节}}】）。
【反方】最可能推翻结论的 3 个理由：{{反方理由}}；其中哪一条我目前无法排除。
【代价】如果判断错了，损失是 {{金额/时间/机会}}，可承受度 {{高/中/低}}。
【待补】还需要我确认的 {{N}} 条信息：{{清单}}。
```

适合谁：要向老板、投委会、合伙人一句话说清「做不做」的人；决策窗口只有 5 分钟阅读时间。

### 2. 赛道地图（Market Map）

```
【玩家分类】按 {{商业模式/客户类型/价格带}} 把玩家分 3–5 类，每类 2–4 家代表 + 一句话定位。
【对比维度】{{收入规模 / 客单价 / 客户结构 / 融资阶段 / 区域 / 产品形态}}，未知的写「待核实」。
【格局判断】CR3、增长最快的一类、正在被替代的一类。
【空白位】现有玩家都没做好的 {{2–3}} 个需求点，标注「有证据 / 仅推断」。
【对我们的含义】以我们 {{现有能力}} 的起点，最现实的切入位是 {{位置}}，理由是 {{理由}}。
```

适合谁：做市场进入、产品定位、投资标的初筛的人；需要的是格局感而不是深度细节。

### 3. 深度调研报告（假设树驱动）

```
【主问题】{{一个可用「是/否/试点」回答的决策问题}}。
【假设树】把主问题拆成 {{4–6}} 个可验证子问题，每个子问题给：判断标准 + 所需证据 + 现有材料能否回答。
【逐项验证】按子问题顺序给证据，区分「事实 / 推断 / 建议」三类，事实必须带来源。
【情景】给出保守/中性/乐观三种情景及各自触发条件。
【结论与下一步】推荐方案 + 前 90 天的验证动作 + 明确的「不做什么」。
```

适合谁：真的要花钱、要立项、要向外部交代的研究者与咨询顾问；读者会拿它对抗。

## 术语与合规边界

**必用术语（首次出现给中英对照）**

- 决策问题（decision question）：能用「做/不做/先试」回答的问句，不是「了解一下 X」。
- 假设树（issue tree）/ 相互独立完全穷尽（MECE, Mutually Exclusive Collectively Exhaustive）：拆问题的结构。
- 口径（measurement basis）：同一句话「市场 500 亿」，按 GMV 还是收入差一个量级。
- 一手信源 / 二手信源：访谈纪要、财报、招标公告是一手；媒体转述、行业研报是二手。
- 证据等级：实测量化 > 一手访谈 > 官方公开数据 > 二手研报 > 自媒体。
- 尽职调查（DD, Due Diligence）、总可服务市场（TAM）/ 可服务市场（SAM）/ 可获得市场（SOM）。
- 基准对比（benchmark）、敏感性分析（sensitivity analysis）、幸存者偏差（survivorship bias）。

**合规红线（写进提示词，别指望模型自觉）**

- **不许编造数字、来源、机构名、报告名**：没有就写「待核实」；引用必须能回溯到用户提供的文件名与章节。
- 未公开信息、内幕消息、竞业限制期内的客户资料：不写进提示词，也不要求 AI 使用。
- 事实与建议必须分段：调研报告里「我们判断」不能伪装成「行业数据」。
- 涉及投资标的的结论，加一句「本文为研究分析，不构成投资建议」。
- 个人信息与客户身份脱敏（姓名、联系方式、合同金额可区间化）。
- 观点来源注明出处（用户笔记 / 官方文档 / 公开报告），不写「有研究表明」这种无主体说法。

## 填好的示例

场景：一家做企业内训的小公司，要不要在 2026 年 Q2 投入新产品线。这是一份可以直接改数字使用的完整提示词。

```
你担任我的研究分析师。角色只影响语气和受众，不要用「专家身份」替代证据。

## 决策问题
2026 年 Q2 之前，我们是否投入 3 名全职讲师 + 40 万元预算，开发并投放「企业 AI 应用内训」产品线？
请在三个选项中选一个并说明理由：进入 / 不进入 / 先做付费试点再决定。

## 决策者与截止时间
决策者：公司总经理（看重现金流回正，不希望新增固定人力）。需要在他 2026-04-30 的季度会上使用。

## 分析范围
- 客户：中国大陆 1000 人以上规模企业的 HR / 培训负责人（L&D）。
- 时间窗口：2024-01 至 2026-03 的公开信息 + 我提供的客户访谈纪要。
- 信源分层：一手 = 我提供的 12 份客户访谈纪要（文件【访谈纪要-01】至【访谈纪要-12】）、公开招投标公告；二手 = 上市公司年报、行业协会公开报告。没有来源的内容不要写成事实。

## 必须回答的 5 个子问题
1. 需求是否真实存在，且企业愿意为此单独立预算？（判断标准：至少 5 份访谈里出现明确付费意愿或已发生采购）
2. 预算从哪个科目出（培训费 / 数字化专项 / 人力发展），谁签字？
3. 替代方案是什么：客户自建团队、买通用大模型课程、还是用免费公开课？我们相对替代方案的优势证据是什么？
4. 我们缺什么能力（课程研发、交付讲师、案例库），补的成本大概多少？
5. 如果只做 1 个最小可卖产品，应该是什么？验证它的 3 个指标是什么？

## 边界（违反即返工）
- 不要给没有口径的市场规模数字；凡出现数字，必须同时写：口径、期间、来源。
- 无法核实的写「待核实」，并单独列成清单，不要用推测填空。
- 区分「事实 / 推断 / 建议」，每段开头标明属于哪一类。
- 明确写出「不做什么」，以及如果我们判断错了，最大损失是多少。

## 输出结构（Markdown）
1. 一页纸结论（≤300 字，含推荐选项与 3 条核心理由）
2. 证据正文（按 5 个子问题，每条含来源引用【文件名|章节】）
3. 反方观点 3 条（哪一条我目前排除不掉）
4. 三选一方案对比表（投入、6 个月现金流影响、验证周期、失败信号）
5. 待核实信息清单（我需要补什么）
```

> 这段为什么这样写：决策问题写成「三选一」而不是「分析一下」，报告才有终点；信源分层 + 引用格式把幻觉逼到「待核实」栏；强制反方 3 条和「判断错了损失多少」是咨询交付里最容易被省略、却决定报告能不能被采用的两块。
> 换模型：给推理模型（GPT-6 系）时删掉任何「请分步骤思考」的表述，只留目标、成功标准、边界；给 Gemini 4 补 1 个「合格结论长什么样」的短示例；Claude 5.x 把信源分层放进 `<documents>` 标签并按 `<source>` 标注。

## 常见坑

1. 只写主题不写决策问题（「调研一下 AI 培训市场」）→ 输出必然变成百科词条；改成「我们该不该在 Q2 投入 X」。
2. 不定义市场规模口径 → 不同来源的数字互相打架；要求每个数字带口径、期间、来源。
3. 让 AI「给出处」却不给材料 → 编造率最高的一步；改成「只允许引用我提供的文件，缺的写待核实」。
4. 只要支持结论的证据（确认偏误）→ 强制要求「反方 3 条 + 排除不掉的 1 条」。
5. 把二手新闻、研报摘要当一手事实 → 要求每条结论标注证据等级。
6. 一次性要「调研 + 报告 + 汇报话术」→ 拆三轮：先结论、再证据、最后讲稿（李厂长《15分钟学会提示词9大秘籍》秘籍 8：指令过多要拆）。
