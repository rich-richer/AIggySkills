# 电商与零售（E-commerce）

**什么时候读这个文件**：用户要做商品标题/卖点/详情页、客服话术、活动策划、选品或差评处理。
**读完你会得到**：电商需求必须问的 7 个参数、3 种交付骨架、广告法与平台规则的硬边界，以及一个可直接用的详情页文案提示词。
**分工**：创作结构与多方向备选见 `../modes/creative.md`；短视频/直播脚本见 `./media-content.md`。

## 什么时候用

- 用户会说：「写个商品标题」「详情页文案」「客服话术」「这个差评怎么回」「双 11 活动方案」。
- 用户给的是商品参数表，要变成「人话卖点」，并且能直接在平台落地。
- 内容会对外发布，涉及绝对化用语、特殊类目资质、价格标示——合规风险高于文案质量。
- 用户要「多平台一起写」：淘宝/京东/拼多多/抖音/独立站的规则与语言差别很大，需要分别处理。

## 行业参数

| 维度 | 必须问到 | 用户不答时的默认 | 采访编号 |
|---|---|---|---|
| 平台与类目 | 哪个平台、什么类目、是否有特殊资质 | 淘宝/天猫，普通类目 | `I-G1` |
| 目标客群与价格带 | 谁买、自用还是送人、售价与 2 个竞品差异 | 25–40 岁女性自用，中端价位 | `I-G1` / `I-P1` |
| 商品事实 | 规格、材质、产地、质检/认证、库存与发货 | 只用用户给的参数，不编参数 | `I-G5` |
| 流量来源 | 搜索 / 推荐 / 直播 / 私域 | 搜索为主，关键词优先 | `I-G1` |
| 售后政策 | 七天无理由、退换条件、运费险 | 按平台默认规则写 | `I-G3` |
| 合规限制 | 类目资质、可用的功效表述、价格标示依据 | 按最保守口径写，不碰功效断言 | `I-G3` |

## 常用体裁 × 3

### 1. 商品标题与卖点（搜索场景）

```
【标题】{{品牌/品类词 + 属性词 + 场景词 + 规格}}，≤30 字，不堆重复词，不写绝对化用语。
【核心卖点】{{3}} 条，每条：一句人话 + 一个可验证的依据（参数/材质/检测报告编号）。
【场景】{{2}} 个具体使用场景（谁在什么时候用）。
【对比】与 {{1}} 个竞品的差异点，只写事实差异，不贬低对方。
```

适合谁：靠搜索流量吃饭的店铺运营；标题决定被不被搜到，卖点决定点不点。

### 2. 详情页文案（转化场景）

```
【首屏】一句话说清「这是什么 + 解决什么问题」，配图建议。
【痛点】{{2–3}} 个具体场景，不写「你是不是也这样」这类空话。
【方案】产品怎么解决：结构 → 依据（参数/工艺）→ 用户能感知的差别。
【信任】质检、材质、产地、售后、真实可核实的资质；不得虚构销量与评价。
【规格与须知】尺寸/容量/适配机型/发货时效/退换规则。
【行动】{{下单/领券/咨询}}，只给 1 个主行动。
```

适合谁：需要把参数表翻译成购买理由的运营与美工；也是客服话术的素材来源。

### 3. 客服话术与差评回复

```
【场景】{{催发货 / 质量问题 / 退换 / 差价 / 差评}}。
【先共情】一句承认对方感受，不辩解。
【给事实】依据平台规则与订单事实说明能做什么、不能做什么（给规则出处）。
【给方案与兜底】{{A/B}} 两个可选方案 + 时效；超出售后权限时升级给谁、多久回复。
【禁用】不承诺平台外补偿、不诱导改评价、不索要好评返现。
```

适合谁：日咨询量大的客服团队；把「规则 + 共情 + 方案」写成模板，比让客服自由发挥稳定。

## 术语与合规边界

**必用术语（首次出现给中英对照）**

- 转化率（CVR）、点击率（CTR）、客单价（AOV）、商品交易总额（GMV）、广告投产比（ROAS）。
- 库存量单位（SKU）、店铺评分（DSR）、退货率、复购率、私域流量。
- 独特卖点（USP）、搜索关键词、种草、主图/详情页、履约时效。

**合规红线**

- **不得使用绝对化用语**（「最」「第一」「国家级」「顶级」等），具体以现行《广告法》文本与平台规则为准。
- **不得虚假宣传**：不虚构销量、评价、检测报告、产地、资质；参数必须与实物一致。
- 食品、化妆品、保健食品、医疗器械等特殊类目：需资质与备案，非医疗类目**不得宣称疗效**（「治疗」「根治」「降血糖」一律不写）。
- 价格标示：划线价须有真实依据，不虚构原价、不搞虚假折扣。
- 不诱导好评、不骚扰买家、买家信息脱敏（对应《个人信息保护法》）；平台规则变化快，活动与审核标准**以发布当期平台规则为准（待核实）**。

## 填好的示例

场景：一款保温杯的详情页文案。参数可替换。

```
你帮我写一款保温杯的详情页文案，投放在淘宝/天猫。

## 商品事实（只用这些，不要编参数或认证）
- 316 不锈钢内胆，容量 480ml，杯身 6.5cm 直径，可放进大部分车载杯架；净重 280g。
- 保温：实验室条件下 95℃ 热水 6 小时后 ≥65℃（检测报告编号我另外提供）。
- 两种颜色：雾灰、奶白；带一键开盖与防漏硅胶圈；不含 BPA。
- 售价 139 元，竞品价位 99–169 元；售后：七天无理由，非人为损坏 1 年换新。

## 目标客群
25–40 岁通勤上班族，自己用；主要搜索词是「保温杯 办公」「保温杯 车载」。

## 你要产出
1. 标题 3 个备选：≤30 字，含品类词 + 属性词 + 场景词，不堆砌、不用绝对化用语。
2. 详情页文案结构：首屏一句话 → 2 个通勤场景痛点 → 3 个卖点（每条配可验证依据）→ 信任模块 → 规格与须知 → 1 个主行动。
3. 卖点每条给一句主文案（≤15 字）+ 一句补充说明，说明必须能对应上面的参数。
4. 客服 FAQ 5 条，含"能不能装碳酸饮料""漏水怎么办""能不能进洗碗机"。
5. 3 个不得使用的表述示例（说明为什么不能用，帮我避坑）。

## 边界
- 不写「最保温」「第一名」「医用级」这类绝对化或误导表述。
- 不虚构销量、评价、检测结论；检测数据只按我给的写，且注明"实验室条件下"。
- 不宣称任何保健或治疗效果。
- 划线价、活动价我不提供，你就不要自己编，写「价格以商品页为准」。
- 平台规则可能调整，涉及资质与审核的部分提示我按当期规则核对。
- 格式：Markdown；文案分「标题 / 首屏 / 卖点 / 信任 / 规格 / FAQ」六块；中文；语气口语、克制、不堆感叹号。
```

> 这段为什么这样写：强制每个卖点挂一个「可验证依据」，是让详情页不变成形容词堆砌的唯一办法；把「不得使用的表述示例」也作为产出，等于让模型帮你做合规自查；「不编价格与活动」直接掐掉最常见的虚构风险。
> 换模型：推理模型给事实、目标与边界即可；小模型需要固定六块结构与一条填好的卖点示例，否则会退化成通用模板。

## 常见坑

1. 只给商品名不给参数 → 只能写空话卖点；先把规格/材质/检测数据列清楚。
2. 用「最/第一/国家级」等绝对化用语 → 广告法风险；全部替换成可验证的具体描述。
3. 编造销量、评价、检测报告 → 平台处罚 + 消费者投诉；只能写用户提供且可核实的。
4. 一个提示词同时要标题 + 详情页 + 客服 + 活动页 → 拆开写（李厂长《15分钟学会提示词9大秘籍》秘籍 8）；忽略售后与规格须知 → 退货率飙升，详情页必须含发货时效、适配范围与退换规则。
