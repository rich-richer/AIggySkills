# 采访脚本（Interview）

严格采访是本 skill 的核心：**不猜关键信息**。但"严格"不等于"一次只问一句"——而是**分批问完、每轮问的都是会改变输出的问题**。

## 使用规则

1. **最多 3 轮，每轮 ≤5 问**，编号列出，用户可一次答完。
2. 第 1 轮固定问 `I-G1`–`I-G4`（`I-G5` 视情况）；**`I-G2` 成功标准必须拿到**。
3. 第 2 轮按模式和领域从下表抽取，只问"答案会改变提示词写法"的。
4. 第 3 轮复述确认（`I-F1`），然后动笔。
5. **逃生门**：用户说"先给草稿""别问了""直接来"→ 立刻出 `DRAFT` 版，用「缺省假设表」标明假设，末尾问"哪条假设要改？"。
6. **不重复问**：用户已经说过的不要再问；用户答案含糊时，用**二选一**逼具体（"是给老板看的决策摘要，还是给同事看的操作指南？"）。
7. 用户一次答了 3 个问题 → 直接进下一轮缺口，不要走形式。
8. 用户明显不耐烦（"随便写一个"）→ 降到 3 问（任务、成功标准、边界），其余全部假设。

## 第 1 轮：定位（所有任务都问）

| 编号 | 问题（可直接照抄） | 为什么必须问 | 缺省假设 |
|---|---|---|---|
| `I-G1` | 这份输出最终**给谁看、用来做什么决定或动作**？ | 决定受众、深度、语气、结论强度 | 通用读者、仅供参考 |
| `I-G2` | **什么样的结果算合格？** 能举一个你觉得好的例子，或一个明显不合格的例子吗？ | 没有成功标准就无法判断提示词好坏 | 标 `DRAFT`，不承诺质量 |
| `I-G3` | **绝对不能出现什么？**（编造数据 / 太长 / 某种措辞 / 违规内容 / 暴露隐私） | 边界比正面要求更能约束输出 | 加通用边界：不编造、不确定就标注 |
| `I-G4` | 给**哪个模型**用？（不确定就说不知道）**一次性用还是反复用**？ | 推理模型/图像模型/API 的写法完全不同；复用才值得做变量槽 | 通用聊天模型、一次性使用 |
| `I-G5` | 手里有**资料 / 旧稿 / 示例**吗？ | 有资料就用"喂模式"，没资料要加检索要求 | 无资料，按通用知识写并加"标注不确定" |

> 问法示范（把 5 个问题压成一条）：
> "动手前先确认 5 件事：① 给谁看、用来做什么？② 什么样算合格，能举个例子吗？③ 绝对不能出现什么？④ 给哪个模型、用一次还是反复用？⑤ 有现成资料或旧稿吗？"

**动词化规则（`I-G1` 的后处理，不新增问题）**：用户要的是给人看的交付物名词（汇报、报告、方案、文案、PPT…），或用形容词代替标准（「专业点」「让人想买」），就把 `I-G1` 的回答改写成一句动词目标：`在【时间／场合】内，让【谁】【看清／相信／决定／去做】【什么】`。拿不准时把追问换成：「这份 ×× 交出去后，你希望看的人做什么？」——答出具体动作就做，答「存档／走流程」就不做。抽取、自动化、图像视频、操作、学习类不做。完整判定见 `./techniques/ambition-4d.md` 第 2 节。

## 第 2 轮名额怎么分（硬规则，避免"候选 8 条、名额 5 个"）

第 2 轮**最多 5 问**，按优先级取，不要贪：

1. **P0 必问（最多 3 条）**：该模式的核心提问——调研是 `I-R1/I-R2/I-R3`，报告是 `I-P1/I-P3`，抽取是 `I-E1/I-E2`，学习是 `I-L1/I-L2`，操作是 `I-O1/I-O2`，Agent 是 `I-A1/I-A3`，图像视频是 `I-M1`，自动化是 `I-W1/I-W2`，创造是 `I-C1/I-C2`。
2. **P1 选问（最多 2 条）**：领域补问（**最多选 1 个领域**）+ `I-E3`（材料规模）+ `I-F2`（要不要试跑）+ `I-D1`／`I-D2`（雄心补问，仅 research、report、有转化或决策目标的 creative）。
3. **超出名额的候选**：不要硬塞，写进「缺省假设表」，交付时把假设列给用户看。
4. 如果第 1 轮已经拿到的信息能推出某个 P0（用户自己说了受众、篇幅），就跳过它，把名额让给别的。

**编号共用约定**：`I-P1/I-P2/I-P3`（决策者、结论倾向、风险成本）是**决策类任务通用**，调研与报告都用；`I-L1/I-L2`（水平、目标与形式）是**学习与教培共用**。领域文件里出现这两组编号时按本文件语义理解，不是写错。

## 第 2 轮：按模式抽问

### 创造类（`modes/creative.md`）
| 编号 | 问题 | 缺省假设 |
|---|---|---|
| `I-C1` | 有 2–3 个你喜欢的**风格参照**吗？（链接、截图、一段文字都行） | 给 2 个方向对比，让用户挑 |
| `I-C2` | 想要**几个方向**？一个打磨到底，还是先给 3 个选？ | 先给 3 个方向 |
| `I-C3` | 篇幅大概多少？**有什么词或套路绝对不要**（AI 味、鸡汤、夸张）？ | 300 字内、去 AI 味 |

### 深度调研（`modes/research.md`）
| 编号 | 问题 | 缺省假设 |
|---|---|---|
| `I-R1` | 信源范围：**中文够用还是要覆盖英文/全球**？要不要一手数据（财报、访谈）？时效要求（近 1 年/3 年）？ | 中英都要、近 2 年、二手为主 |
| `I-R2` | 交付结构：执行摘要 + 分章，还是要点式？大概多少字？ | 执行摘要 + 4–6 章，3000 字 |
| `I-R3` | 要不要**每个关键数据都标来源**（文件名+页码/链接）？ | 要，关键数据必须标来源 |

### 项目/商业报告（`modes/report.md`）
| 编号 | 问题 | 缺省假设 |
|---|---|---|
| `I-P1` | **谁做决策、要决定什么**？（批预算 / 选方案 / 立项 / 汇报进度） | 中层管理者、选方案 |
| `I-P2` | 结论要**中立陈列**，还是**明确推荐一个方案**？ | 明确推荐 + 理由 |
| `I-P3` | 要不要**成本、风险、不做的后果**？ | 要，单独一节 |

### 抽取/结构化（`modes/extraction.md`）
| 编号 | 问题 | 缺省假设 |
|---|---|---|
| `I-E1` | 要抽**哪些字段**？有没有**固定取值**（分类枚举）？ | 按用户描述列出字段，枚举先给 3–5 个 |
| `I-E2` | 原文没提到时怎么办？**留空 / null / "未提及"**？ | 统一写 `null`，不猜 |
| `I-E3` | 一次处理多少条？能给 **1 条真实样例**吗？ | 单条，附 1 个示例 |

### 学习/解释（`modes/learning.md`）
| 编号 | 问题 | 缺省假设 |
|---|---|---|
| `I-L1` | 你现在的**水平**（完全新手 / 有基础 / 要精通）？ | 有基础 |
| `I-L2` | 目标是**考试/应用/讲给别人听**？喜欢类比、例题还是追问式？ | 应用导向 + 类比 + 每节末尾自测 |

### 操作 SOP（`modes/procedure.md`）
| 编号 | 问题 | 缺省假设 |
|---|---|---|
| `I-O1` | **软件/版本/系统**是什么？（如 Notion 最新版、macOS、某台设备） | 最新版、macOS |
| `I-O2` | 卡在哪一步？**允许失败重试吗**？出问题要找谁？ | 卡在中段，允许重试，自行排查 |

### Agent / 编码（`modes/agentic.md`）
| 编号 | 问题 | 缺省假设 |
|---|---|---|
| `I-A1` | 它**能用哪些工具**？有没有不能碰的目录/接口？ | 只读 + 可写当前目录 |
| `I-A2` | 哪些操作**必须先问你**（删除、发布、花钱、对外发送）？ | 破坏性/对外操作必须先问 |
| `I-A3` | **什么时候停**？（跑几次、花多少时间、什么条件下放弃） | 最多 5 次工具调用，不确定就停 |

### 图像 / 视频（`modes/image-video.md`）
| 编号 | 问题 | 缺省假设 |
|---|---|---|
| `I-M1` | **主体、场景、风格、比例**？要不要文字/logo？画面上绝对不能出现什么？ | 16:9、写实风格、无文字 |

### 自动化节点（`modes/automation.md`）
| 编号 | 问题 | 缺省假设 |
|---|---|---|
| `I-W1` | **变量从哪来**（表单、上一步输出、数据库字段）？ | 上一步输出 |
| `I-W2` | 输出被**下游什么消费**（解析 JSON / 发邮件 / 存表）？ | 下游解析 JSON |

### 雄心补问（占 P1 名额，见 `./techniques/ambition-4d.md`）
| 编号 | 问题 | 缺省假设 |
|---|---|---|
| `I-D1` | 这件事**做成之后，接下来要发生什么**？（目标之上的目标） | 以动词句为终点，不再上推 |
| `I-D2` | 这件事的动词，**哪些行当天天在做**？要不要安排一方专门挑刺（红队）？ | 由我按动词推荐 2 个领域 + 1 个红队，并标注「可替换」 |

## 第 2 轮：按领域补 1–2 问

| 领域 | 补问 |
|---|---|
| 深度调研/咨询 | 要不要竞争格局、市场规模、政策/监管视角？ |
| 项目报告 | 预算/周期/团队规模的量级？有没有既定方案要对比？ |
| 自学 | 学完要产出什么（笔记/作品/讲一遍）？ |
| 教培 | 学员是谁、什么基础、课时多长？（用 `I-L1`/`I-L2` + 学员画像） |
| 自媒体 | 平台（抖音/小红书/公众号/视频号）？账号定位、目标（涨粉/转化）？ |
| 职场沟通 | 你和对方的关系（上级/平级/客户）？要不要给对方留台阶？ |
| 科技产品 | 用户是谁、解决什么场景？有没有技术栈/合规限制？ |
| 金融 | 读者是散户还是专业？要不要免责声明？ |
| 健康 | 是科普还是个人建议？（个人建议必须加"就医"边界） |
| 法律 | 哪个法域？是要模板还是要解释？（必须加"不构成法律意见"） |
| 电商 | 平台、客单价、目标（转化/复购/清库存）？ |
| 学术 | 学科、期刊/会议层级、引用格式？ |
| 生活服务 | 预算、时间、地点、可接受的替代方案？ |

## 第 3 轮：确认（≤3 问）

| 编号 | 问题 |
|---|---|
| `I-F1` | 复述一遍：「你要的是 **{任务}**，目标是 **{动词句}**（未做动词化则省略这一项），给 **{受众}** 用，成功标准是 **{标准}**，不能出现 **{边界}**。有要改的吗？」 |
| `I-F2` | 交付后要不要我**再体检一遍**，或者给一段**试跑指令**让你自己验证？ |

## 缺省假设表（用户不回答时用）

| 信息 | 默认值 | 标注方式 |
|---|---|---|
| 受众 | 通用读者 | 提示词里写"假设读者无背景" |
| 篇幅 | 800–1500 字 | 在变量槽里设为可调 |
| 语气 | 专业但不端着 | 用"简洁直接、不用形容词堆砌" |
| 成功标准 | 未定 → 标 `DRAFT` | 交付时明确说"缺成功标准，无法判断好坏" |
| 模型 | 通用聊天模型 | 附一句"如果是推理模型，删掉 X" |
| 资料 | 无 | 加"不确定的信息标注（未核实）" |

## 采访中的三个禁忌

1. **不要问用户自己能查到的事**（模型参数、软件版本差异）——自己查或给默认值。
2. **不要一次问超过 5 个**——超过就拆轮次，或挑最关键的 3 个。
3. **不要用开放式大问题**（"你想要什么风格？"）——给选项：**A 冷静克制 / B 热情口语 / C 学术严谨**。
