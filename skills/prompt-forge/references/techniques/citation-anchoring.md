# 引用锚定与降幻（Citation Anchoring）

**什么时候读这个文件**：要基于多份资料写报告或综述；交付物会被追问"这句哪来的"；或者你担心模型编数据、编页码。
**读完你会得到什么**：可直接粘贴的引用格式与缺信息话术、一份完整的带引用提示词、以及如何抽查引用是否真的存在。

## 什么时候用

- 用户给了 PDF / Excel / 多份文档，要求"基于这些资料写"。
- 交付物用于决策（投资、汇报、评估），错一个数字就有代价。
- 用户说"要能查到出处""每个数据要有来源"。
- 输出里出现了你没给过的数字、年份、公司名——典型幻觉信号。
- 要对比多份资料之间的观点冲突。

## 怎么做

1. **给资料命名，并要求固定引用格式**：`【{文件名}|{页码或章节}】`，例如 `【report_A.pdf|第 3 页】`。格式必须写死，只说"请引用来源"等于没要求。
2. **要求引用贴近断言**（内联优先，不要文末统一列参考文献）：引用挂在段末时，一段里三个数据你根本不知道哪个对应哪条来源。
3. **给缺信息逃生口**：写死一句"如所需信息未出现在资料中，请明确说明：'根据所提供的资料，此部分信息暂缺。'"，并禁止猜测、禁止用通用知识补全。
4. **区分资料来源**：要求标明哪句来自资料、哪句来自模型自身知识（如注明"（非资料内容，来自通用知识，请核实）"）。
5. **抽查**：交付前随机抽 3 条引用回原文核对。抽不中就说明约束没生效——先改提示词，不要人工逐条补。
6. **长材料加二次锚定**：输入超过 1 万 token 时，开头要求它先复述引用约束，结论锚定到具体章节，末尾再重复一次引用要求。

## 示例

差：

```text
这是我们的三份行业报告，帮我写一份市场分析。
要求引用来源，不要编造。
```

→ 结果通常是数据对得上、页码全是编的。"不要编造"这类否定指令挡不住幻觉，因为它没给"做不到时该怎么办"的出口。

好（可直接用）：

```text
# 任务与角色
你是一名商业分析助理，用中文输出。

# 背景
你将收到三份资料：report_A.pdf、data_sheet_B.xlsx、interview_C.md，
涵盖某行业 2024–2025 年的市场数据与趋势。

# 目标
1. 基于这三份资料撰写一份结构化市场分析报告。
2. 每个关键数据、每个结论性判断都要标注来源。
3. 缺失信息要明说，不要用常识或推测补齐。

# 引用规则
- 引用格式固定为：【{文件名}|{页码或章节}】，例：【report_A.pdf|第 3 页】。
- 引用必须紧跟它所支持的那句断言，不要集中放在段末或文末。
- 如所需信息未出现在资料中，请明确写："根据所提供的资料，此部分信息暂缺。"
- 若某句来自你的通用知识而非资料，请在该句后标注"（非资料内容，来自通用知识，请核实）"。
- 三份资料互相矛盾时，并列双方说法与出处，不要自行择一。

# 输出格式
Markdown：# 摘要 / ## 市场趋势 / ## 竞争格局 / ## 数据分析 / ## 结论与建议
```

缩略示例输出（放在提示词里用来定格式）：

```markdown
### 市场趋势
该品类 2025 年上半年线上销售额同比增长 18%【data_sheet_B.xlsx|Sheet1 第 2 行】。
线下渠道同期下降约 6%【report_A.pdf|第 7 页】。
三家访谈对象均提到价格战加剧【interview_C.md|第 2 节】。
库存周转天数的最新数据未在资料中出现：根据所提供的资料，此部分信息暂缺。
```

说明：重点不是"要求引用"，而是**把引用的形状、位置、缺信息时的替换话术全部写死**。引用要求本身就是降幻手段——要求引用会让模型必须犯两次错（先编内容、再编出处）才可能不被发现，成功率因此显著下降。

## 常见坑

- 不要只写"请标注来源"。不写格式，模型会自创脚注、括号、"据某报告"，全都不可查。
- 不要把引用堆在文末参考文献里。一段多断言时无法定位，必须内联。
- 不要只下"禁止编造"的禁令。禁止类指令必须配一个"做不到时输出什么"的替代动作，否则模型只有硬编一条路。
- 不要让它"合理补全缺失数据"。这是幻觉最常走的门；缺失一律走"暂缺"话术。
- 不要把引用数量当质量指标。凑引用比没引用更糟——看着有依据，实际全错。抽查 3 条比通读全文更有效。
- 长材料里不要只在开头写一次引用要求。超过 1 万 token 必须在末尾再锚定一次。
