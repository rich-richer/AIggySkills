# 反思校对与 rubric 自评（Self-critique）

**什么时候读这个文件**：任务的正确性你自己很难判断；输出要给客户或领导；或者你需要一份"可信度"的交代而不只是答案。
**读完你会得到什么**：先自评后作答的两段式写法、可判定的 rubric 模板、以及独立验证的正确做法（以及为什么同轮自检没用）。

## 什么时候用

- 输出会被当作决策依据：数据分析、行业判断、方案建议、诊断结论。
- 任务依赖模型自身知识（而不是你给的资料），你不确定它到底知不知道。
- 用户明确说"要准确""不能出错""给我一个可信的版本"。
- 要批量打分、评估质量、做 eval 用例。
- 你在给提示词做体检，需要判断该加自检还是该加资料。

## 怎么做

1. **先自评，再作答**（顺序不能反）：要求它在正式回答前，用 120 字内交代三件事——知识掌握程度、主要风险、整体可信度（高/中/低）。这会把"它知道多少"显性化，你能据此决定要不要补资料。
2. **生成验证问题 → 独立作答 → 重写**。关键在"独立"：在**新会话**里只回答验证问题（不给原答案），再带着验证结论回来重写。同一轮里说"你自己检查一下"会被原答案带偏。
3. **rubric 自评**：给 3–5 条可判定的评分项，每条写清"合格长什么样、不合格长什么样"，要求先逐条打分再改写不合格项。
4. **能确定性验证就别用模型投票**：代码跑测试、数字重算、字段对 schema、引用回原文抽查——验证器永远优于"再问一遍模型"。
5. **自评要带反例**：给一条"这不算合格"的样例，否则它的自评标准会自己往下调。

rubric 模板（把 `{{}}` 换成你的判据）：

```text
先不要输出正文。按下面 4 项给自己的准备情况打分（每项 1–5 分），
各写一句理由；任一项低于 4 分，先说明你缺什么信息，并问我是否补充。

1. 依据充分性：结论是否都有我提供的资料或可核实来源支撑？
   5 分 = 每条结论都有出处；1 分 = 主要靠推测。
2. 事实可靠度：涉及的数字、日期、人名，你能确认的占比多少？
3. 覆盖完整性：我提出的 {{N}} 个问题是否都被回答？
4. 边界遵守：是否出现了我明令禁止的 {{禁止项}}？

打分完成后输出正式答案，并在末尾列出"我仍不确定的 3 点"。
```

## 示例

差：

```text
帮我分析一下这个行业明年的趋势，要准确。
```

→ 得到一段结构完整、语气笃定、但你完全无法判断真假的文字。

好（两段式 + 独立核验）：

```text
# 第一步：先自评（120 字内，不要输出正文）
- 你对"中国宠物食品行业 2026 年趋势"的知识掌握程度如何（高/中/低）？
- 这个回答最大的 3 个潜在风险是什么（时效、数据、地域）？
- 整体可信度评级（高/中/低）？
- 先说明你的知识截止到什么时候。

# 第二步：正式作答
基于我提供的两份材料（附后）+ 你的通用知识，输出：
1. 3 条趋势判断，每条一句话；
2. 每条判断后标注：来源（材料 / 通用知识）+ 可信度（高/中/低）+ 依据强度（强/中/弱）；
3. 明确列出 2 条"我无法判断、需要外部数据才能回答"的问题。

# 第三步：自检
按 rubric 逐条打分（依据充分性 / 事实可靠度 / 边界遵守），
低于 4 分的项写出你打算怎么改，然后给我修订版。

# 规则
- 不确定的数字直接写"（待核实）"，不要给一个估算区间伪装成数据。
- 禁止出现"据权威机构""相关研究表明"这类无出处表述。
```

独立核验那一步要**单独开一个新会话**，提示词像这样：

```text
以下 3 个判断，请只回答"成立 / 不成立 / 证据不足"并说明理由，不要评价其他内容：
1. ……
2. ……
3. ……
```

说明：这一步不看原答案，才叫独立验证；如果在新会话里再带上原回答，模型会替它辩护。

## 常见坑

- 不要在同一轮里说"写完自己检查一遍"。原答案还在上下文里，模型只会给它辩护；独立作答要在新会话，或显式要求"不要参考上文"。
- 不要把 rubric 写成"是否专业""是否有深度"。无法判真假的评分项会给出一致的 5 分。
- 不要用"再问一遍模型"代替确定性验证。能跑测试、能重算、能对 schema 的任务，用验证器。
- 不要只加自评不加反例。没有反例，合格线会随着输出一起往下调。
- 不要让自评覆盖掉正文。限定字数（比如 120 字内）并明确"先自评、后作答"，否则它会把自评当交付物。
- 不要用身份头衔顶替可信度。"你是世界级分析师"不会提升事实准确度，反而可能降低（162 个角色 × 2410 题无提升，MMLU 71.6 → 66.3，见 `../models.md` 的判断规则）。
